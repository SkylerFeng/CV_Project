# Video Super-Resolution Project

This repository contains a complete video super-resolution project following the three-part assignment structure:

1. **Part 1**: classical and CNN baselines.
2. **Part 2**: BasicVSR++ and Real-ESRGAN reproduction, fine-tuning, inference, and evaluation.
3. **Part 3**: Direction C adaptive hybrid pipeline for controlling hallucination and temporal flickering.

The final system compares a faithful temporal VSR branch, BasicVSR++, with a sharper perceptual branch, Real-ESRGAN. Based on their complementary strengths and weaknesses, Part 3 selectively fuses them with a proxy uncertainty/risk alpha mask.

## Environments

Two environments are used:

```text
.venv        # Part 1, Part 2.2, Part 3, shared scripts
mmagic_env   # Part 2.1 BasicVSR++ / MMagic
```

Create the general environment:

```bash
cd /home/fc/Coding/CV
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
pip install lpips scipy
```

Create the BasicVSR++ environment:

```bash
python3 -m venv mmagic_env
source mmagic_env/bin/activate
pip install --upgrade pip
pip install torch torchvision
pip install openmim
mim install mmengine
mim install mmcv
pip install -e part2_1/mmagic
```

Verify MMagic:

```bash
mmagic_env/bin/python -c "import mmagic; print(mmagic.__version__)"
```

If MMagic installation fails, install PyTorch, MMCV, and MMEngine versions compatible with your CUDA version.

## Recommended Run Order

Run from the repository root.

### 1. Part 1 Baselines

```bash
.venv/bin/python part1/scripts/evaluate_part1_val.py \
  --lr-root data/val/val_sharp_bicubic/X4 \
  --gt-root data/val/val_sharp \
  --ckpt part1/checkpoints/srcnn_x4_epoch20.pth \
  --output part1/outputs/metrics_val_part1 \
  --device cuda
```

See `part1/README.md`.

### 2. Part 2.1 BasicVSR++

```bash
mmagic_env/bin/python part2_1/scripts/infer_basicvsrpp_video.py \
  --input data/val/val_sharp_bicubic/X4/000 \
  --output part2_1/results/basicvsrpp_val000_x4 \
  --fps 30 \
  --device cuda
```

See `part2_1/README.md`.

### 3. Part 2.2 Real-ESRGAN

```bash
.venv/bin/python part2_2/src/train.py \
  --config part2_2/configs/train_conservative.yaml
```

See `part2_2/README.md`.

### 4. Part 3 Direction C Hybrid

```bash
.venv/bin/python part3/scripts/run_adaptive_hybrid.py \
  --config part3/configs/adaptive_hybrid_val000_finetuned_report.yaml
```

See `part3/README.md`.

## Important Notes

- BasicVSR++ should be run with `mmagic_env/bin/python`.
- Real-ESRGAN and Part 3 should be run with `.venv/bin/python`.
- The Part 3 uncertainty/risk map is heuristic, not a learned probabilistic uncertainty estimator.
- The temporal metric is reported as `tLPIPS-proxy` because it does not use optical-flow warping.
- Do not report PSNR/SSIM for no-reference videos without ground truth.
